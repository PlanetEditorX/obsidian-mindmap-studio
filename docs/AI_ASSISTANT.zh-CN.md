# AI 助手说明

## 功能范围

MindMap Studio 的 AI 助手把当前导图范围转换为 Markdown 文本，再通过用户配置的 OpenAI Chat Completions 兼容接口发送。插件内置 OpenAI、DeepSeek、硅基流动、FreeLLMAPI 和自定义接口配置入口，但不会附带 API 密钥。

AI 助手不会修改 `.mindmap` 文件。回答显示在独立窗口中，可复制后由用户决定是否写回导图。

## 上下文范围

### 当前页面

以下入口默认使用当前物理 `.mindmap` 文件的全部节点：

- 工具栏“询问 AI”按钮。
- 命令面板“询问 AI（当前页面或右键节点）”。
- `Ctrl/Cmd+Shift+A`。
- 导图、大纲、文章或通读页面空白处的右键菜单。

“当前页面”不自动拼接整个父子导图文章族，避免意外上传过大的上下文。

### 节点分支

在任一视图中右键节点，选择“询问 AI（此节点及全部子节点）”，插件只转换：

1. 被右键的节点；
2. 该节点的全部后代；
3. 节点内的文字、备注、任务、图片引用、表格和代码等可导出内容。

右键节点后，工具栏 AI 按钮和快捷键会暂时沿用该节点范围。页面空白处右键可恢复为当前页面范围。

目标节点在打开窗口前已被删除时，安全回退到当前页面。

## Markdown 转换与大小限制

发送前窗口会显示：

- 上下文范围；
- 节点数量；
- 字符数量；
- UTF-8 字节大小；
- 当前设置的最大允许大小。

默认上限为 `256 KB`，设置范围为 `32–2048 KB`。超过上限时“发送”按钮禁用，插件不会静默截断内容。可通过右键更小的节点分支缩小范围，或在设置中调整限制。

问题与 Markdown 使用显式边界分隔。系统提示词要求模型只基于导图内容回答，并把导图内可能出现的指令视为普通资料，而不是高优先级指令。

## 接口配置

打开“设置 → MindMap Studio → AI 助手”。每个接口配置包含：

- 名称和启用状态；
- OpenAI、DeepSeek、硅基流动、FreeLLMAPI 或自定义预设；
- Chat Completions 接口地址；
- API 密钥；
- 模型名称；
- 温度；
- 最大输出 tokens；
- 系统提示词；
- 附加请求头 JSON。

切换预设会更新默认接口地址和模型名称，但不会覆盖已经填写的 API 密钥。接口地址既可填写 `/v1` 基础地址，也可填写完整的 `/chat/completions` 地址。自定义接口必须兼容 OpenAI Chat Completions 的 JSON 请求与响应结构。

内置新增预设：

| 预设 | 默认接口地址 | 默认模型或模型建议 |
|---|---|---|
| 硅基流动 | `https://api.siliconflow.cn/v1` | `deepseek-ai/DeepSeek-V4-Flash`、`deepseek-ai/DeepSeek-V4-Pro`、`zai-org/GLM-5.2` |
| FreeLLMAPI | 留空，由用户填写部署地址 | `auto` |

模型输入框提供预设建议，但仍允许直接输入服务端支持的其他模型 ID。

### 检测接口

每个接口卡片都有“检测接口”按钮。检测会验证：

- 基础地址或 Chat Completions 地址是否可访问；
- API 密钥和附加请求头是否通过鉴权；
- 当前模型是否可用；
- 响应是否包含可读取的兼容文本。

检测请求只发送“请回复 OK”的最小提示词，不包含当前页面、节点分支、文件路径或导图 Markdown。检测成功后会显示耗时、实际返回模型和短响应；失败时显示接口返回的错误信息。

填写 API 密钥后，请求自动添加 Bearer `Authorization`。附加请求头只接受字符串、数字或布尔值，并拒绝非法名称、嵌套对象和 CRLF 换行注入。

## 请求与回答

请求固定使用非流式 JSON：

- 系统消息：当前接口的系统提示词；
- 用户消息：用户问题、范围信息、来源路径、大小信息和 Markdown；
- `stream`：`false`。

窗口中的“转换 Markdown → 上传上下文 → 模型处理 → 接收结果”是客户端处理轨迹，用于明确当前阶段，不表示服务端逐 token 流式返回。

回答支持常见 Chat Completions `choices[0].message.content`、文本数组、`choices[0].text` 和 `output_text` 兼容字段，并使用 Obsidian Markdown 渲染器显示。

## 安全与隐私

- 只有用户点击发送后，Markdown 才会发送到所选服务。
- API 密钥保存在插件 `data.json` 中，不应提交到 Git、同步到公开仓库或发送给他人。
- 自定义接口仅允许 HTTP(S) 地址。
- 插件不自动执行 AI 回答，也不自动覆盖节点。
- 导图可能包含私人笔记、路径和远程图片引用；发送前应核对范围和大小。
- 使用第三方代理时，应确认其隐私政策、日志策略和数据保留方式。

## 操作示例

### 询问当前页面

1. 打开一个 `.mindmap` 文件。
2. 点击工具栏“询问 AI”，或按 `Ctrl/Cmd+Shift+A`。
3. 确认范围显示为“当前页面”。
4. 选择接口、填写问题并发送。

### 询问某个章节

1. 在目标节点上右键。
2. 选择“询问 AI（此节点及全部子节点）”。
3. 确认窗口中的节点数和 Markdown 大小。
4. 发送问题。

### 恢复询问整页

在页面空白处右键，选择“询问 AI（当前页面）”。之后工具栏按钮和快捷键也会恢复整页范围。

## 故障排查

### 没有可选接口

至少启用一个配置，并填写有效接口地址和模型名称。

### 返回成功但没有文本

检查代理是否返回 OpenAI 兼容的 `choices` 或 `output_text` 字段；必要时查看开发者控制台中的原始错误。

### 请求过大

优先右键具体章节缩小范围。提高上限只改变插件侧预检，不能突破模型或代理自身的上下文限制。

### 401 或 403

检查 API 密钥、接口地址、代理要求的附加请求头和账户权限。

### 无法连接

确认服务地址使用 HTTP(S)，网络可访问，并且自定义代理支持 Chat Completions 请求格式。
