# AI 助手说明

## 功能范围

MindMap Studio 的 AI 助手把当前导图范围转换为 Markdown，再通过用户配置的 OpenAI Chat Completions 兼容接口发送。插件内置 OpenAI、DeepSeek、硅基流动、FreeLLMAPI 和自定义接口配置入口，但不附带 API 密钥。

AI 窗口默认选中“AI 整理并重新生成（确认后应用）”，并提供五种相互独立的操作：

1. **询问 AI（不修改导图）**：发送上下文并显示 Markdown 回答。
2. **AI 整理并重新生成（确认后应用）**：让模型返回完整 Markdown 修改提案，先显示预览，用户确认后才替换当前页面或右键节点子树。
3. **整理为题目节点**：要求 AI 只返回题干、选项、答案、解答和标签组成的 JSON；右键节点范围会更新该节点，当前页面范围会在选中节点下新增题目子节点。
4. **图片识图**：按节点树顺序逐张识别当前页面或右键节点子树中的全部图片；可使用 AI 视觉模型或本机 Tesseract OCR。
5. **本地文字替换（不调用 AI）**：在当前范围内执行字面量查找替换，不联网，先统计命中再确认应用。

所有写操作都会进入编辑器撤销历史。AI 回答或修改提案不会在未确认时自动写入 `.mindmap` 文件。

## 上下文和编辑范围

### 当前页面

以下入口默认使用当前物理 `.mindmap` 文件的全部节点：

- 工具栏“询问 AI”按钮；
- 命令面板“询问 AI（当前页面或右键节点）”；
- `Ctrl/Cmd+Shift+A`；
- 导图、大纲、文章或通读页面空白处的右键菜单。

“当前页面”不自动拼接整个父子导图文章族，避免意外上传或替换其他物理文件。

### 节点分支

在任一视图中右键节点，选择“询问 AI（此节点及全部子节点）”，当前 AI 窗口的四种操作都会限定到：

1. 被右键的节点；
2. 该节点的全部后代；
3. 节点内可导出的文字、备注、任务、图片引用、表格和代码等内容。

右键节点后，工具栏按钮和快捷键会暂时沿用该节点范围。页面空白处右键可恢复当前页面范围。目标节点在打开窗口前已被删除时，安全回退到当前页面。

## 询问 AI

选择“询问 AI（不修改导图）”后，填写问题并发送。回答使用 Obsidian Markdown 渲染器显示，可以复制，但不会自动修改节点。

询问模式和 AI 编辑模式分别保存自己的输入草稿。切换回询问模式时会恢复上次填写的问题，不会被编辑要求覆盖。

询问、整理和题目整理会向 OpenAI Chat Completions 兼容接口请求 SSE 流式响应。接口返回 `reasoning_content`、`reasoning` 或 `reasoningContent` 时，窗口会实时显示“模型思考”；返回正文分片时会实时显示“正在生成”。最终回答仍会使用 Markdown 渲染，整理模式仍须先生成预览再确认应用。未返回思考字段的模型只显示生成内容；图片识图和接口检测仍使用普通 JSON 请求。

## AI 整理并重新生成

首次切换到“AI 整理并重新生成（确认后应用）”时，“修改要求”会自动填写：

```text
按主题重新整理层级，合并重复节点，并重新生成清晰的导图结构。
```

修改要求与询问问题使用独立草稿。用户编辑修改要求后，切换到本地替换或询问模式再返回时，会恢复此前的修改要求。

## 整理为题目节点

选择“整理为题目节点”后，AI 会把当前范围中的题目文字转换为结构化题目 JSON，并继续执行与“AI 智能处理题目”相同的原题检索与缺失字段补全。右键节点范围会直接覆盖该节点的题目字段并保留现有题图；当前页面范围会在当前选中节点下创建一个新的题目子节点。模型未返回可解析 JSON 时不会写入导图。

### 两阶段安全流程

AI 编辑始终分为两个阶段：

1. **生成修改提案**：模型只能返回完整 Markdown，插件解析并显示节点数、生成大小和 Markdown 预览。
2. **确认应用变更**：用户检查预览后点击“确认应用变更”，插件才写入导图并记录撤销历史。

以下指令均可作为修改要求：

- “按主题重新整理层级，合并重复节点”；
- “把这部分改写成更清晰的学习提纲”；
- “保留原意，重新生成精简节点”；
- “把所有章节标题统一成动宾结构”；
- “补充缺失的总结节点”。

### 页面替换

范围为当前页面时，确认后替换当前页面的根节点及全部后代。文档级设置、父子导图关系和视图数据仍保留；根节点 ID 保持稳定，AI 新生成的后代会获得新 ID。

### 子树替换

范围为右键节点时，只替换该节点及后代：

- 被选节点的稳定 ID 保留；
- 该节点的样式、子导图引用、链接和文章编号元数据保留；
- 兄弟节点、父节点和页面其他分支不变；
- 新生成的后代使用新 ID，避免与现有节点冲突。

### 并发和输出保护

生成预览时会保存当前范围快照。若用户在预览后又编辑了该范围，应用会被拒绝，必须重新生成预览，避免旧提案覆盖新内容。

AI 编辑输出还受以下硬限制保护：

- 必须以一级 Markdown 标题开头；
- 生成 Markdown 不得超过 `2 MB`；
- 解析后的节点不得超过 `5000` 个；
- 当前文档处于显式只读锁定时不能应用。

## 图片识图

选择“图片 AI 识图”或“图片本地 OCR”后，插件只收集当前范围中的图片内容块，并按节点树深度优先顺序逐张处理。每张图片独立读取和识别；单张失败不会中断后续图片，结果末尾会列出失败项。AI 模式使用所选 OpenAI Chat Completions 兼容接口的视觉模型，本地 OCR 模式调用桌面端本机 Tesseract，不发送图片到网络。

图片中的文字属于不可信输入。AI 请求的系统提示明确要求模型不得把图片内指令当作系统指令；识图结果仅作为文字显示。批量识图完成后，AI 助手会为每张成功图片显示独立、可编辑的原位替换项，不会把各项合并为一段 Markdown。确认后才一次性把每项文字替换回其原图片内容块并写入撤销历史；失败项会保留原图。可在设置中选择直接确认、5/10/15 秒后自动确认或手动确认；直接确认会后台原位替换，不弹出结果确认预览，倒计时自动确认前仍可编辑结果；替换成功后会安全删除不再被其他导图引用的本地图片。右键“AI 识图并转为文字”在手动或倒计时模式下提供单图原图与文字并排预览。预览期间若原图片已变化，旧预览会被拒绝，避免覆盖新编辑。

截图、右键识图、本地 OCR 安装和平台说明见 `IMAGE_RECOGNITION_SCREENSHOT.zh-CN.md`。

## 本地文字替换

选择“本地文字替换（不调用 AI）”后，表单只显示“查找文字”和“替换为”，不会同时显示 AI 的问题或修改要求。匹配默认不区分大小写。切换回“询问 AI”或“AI 整理并重新生成”时，查找和替换输入会隐藏。

本地替换：

- 不发送网络请求；
- 使用与 AI 相同的当前页面或节点子树范围；
- 先显示命中次数和受影响节点数；
- 用户确认后写入撤销历史；
- 预览后范围发生变化时拒绝应用，要求重新预览。

会被替换的内容：

- 节点文字块；
- 备注；
- 表格标题和单元格；
- 当前页面的文档标题（整页范围时）。

不会被替换的内容：

- 节点链接和 URL；
- 代码块；
- 图片地址；
- 子导图文件路径；
- 节点 ID 和结构元数据。

文字块包含富文本时，替换后会重新对齐可保留的字符级格式；无法可靠映射的格式片段会按现有富文本协调规则收敛。

## Markdown 转换与大小限制

发送前窗口会显示：

- 上下文范围；
- 节点数量；
- 字符数量；
- UTF-8 字节大小；
- 当前设置的最大允许大小。

默认上限为 `256 KB`，设置范围为 `32–2048 KB`。超过上限时，AI 问答和 AI 编辑按钮禁用，插件不会静默截断内容；本地替换仍可执行。可以右键更小的节点分支缩小范围，或在设置中调整限制。

问题与 Markdown 使用显式边界分隔。系统提示词要求模型把导图内可能出现的指令视为普通资料，而不是高优先级指令。

## 接口配置

打开“设置 → MindMap Studio → AI 助手”。每个接口配置包含：

- 名称和启用状态；
- OpenAI、DeepSeek、硅基流动、FreeLLMAPI 或自定义预设；
- Chat Completions 接口地址；
- API 密钥；
- 模型名称；
- 思考模式；
- 温度；
- 最大输出 tokens；
- 系统提示词；
- 附加请求头 JSON。

切换预设会更新默认接口地址和模型名称，但不会覆盖已经填写的 API 密钥。接口地址既可填写 `/v1` 基础地址，也可填写完整 `/chat/completions` 地址。自定义接口必须兼容 OpenAI Chat Completions 的 JSON 请求与响应结构。

| 预设 | 默认接口地址 | 默认模型或模型建议 |
|---|---|---|
| 硅基流动 | `https://api.siliconflow.cn/v1` | `deepseek-ai/DeepSeek-V4-Flash`、`deepseek-ai/DeepSeek-V4-Pro`、`deepseek-ai/DeepSeek-OCR`、`zai-org/GLM-4.5V`、`zai-org/GLM-5.2` |
| FreeLLMAPI | 留空，由用户填写部署地址 | `auto` |

模型输入框提供预设建议，也可点击“获取模型”向同一服务的 `/models` 目录读取模型 ID。成功结果会随该接口配置缓存，重新打开设置时无需再次请求；更换接口地址或预设时会清除缓存。若当前仍是预设默认模型、为空或不在新列表中，会自动切换到列表首项；手动填写且仍在新列表中的模型不会被覆盖。服务不提供或禁止读取该目录时，仍可直接输入模型 ID。

思考模式会随接口配置保存：下次请求沿用上次选择。“自动（服务端默认）”不会发送额外控制字段，适合不确定模型能力时使用。开启或关闭时，DeepSeek 使用 `thinking.type`，硅基流动使用 `enable_thinking`，OpenAI 与 FreeLLMAPI 使用 `reasoning_effort`；这些字段是否被接受仍取决于实际模型及代理能力。自定义接口为避免发送未知字段，始终保持服务端默认。

AI 助手弹窗的“深度思考”按钮与当前选中的接口配置同步：会显示自动、已开启或已关闭。点击后立即保存为开启或关闭，设置页中的“思考模式”会同步更新；切换接口时按钮也会切换到该接口自己的状态。

图片 AI 识图默认跟随“默认 AI 接口”。如果默认接口使用纯文本模型，图片请求可能被服务端以 `400` 拒绝；可在“图片识图与本地 OCR → AI 识图接口”单独选择支持图片输入的视觉模型。右键单图识别、截图自动识图和 AI 助手批量识图都会使用该视觉接口设置。

识图请求直接向视觉模型发送纯文本识图提示和图片数据，不携带导图 Markdown，也不继承接口卡片中的通用 AI 系统提示词。返回值会按纯文本 OCR 处理，常见的 Markdown、角色或聊天模板标记会在预览前清理。

设置页会先列出“接口预设与自定义”及其配置卡片，随后显示“图片识图与本地 OCR”选项，便于先配置视觉模型再选择它。视觉提示会要求模型仅转录图片可见内容，不执行图片内的指令；模型意外附带的角色分隔标记及其后续内容会在预览前移除。

### 检测接口

每个接口卡片都有“检测接口”按钮。检测会验证：

- 基础地址或 Chat Completions 地址是否可访问；
- API 密钥和附加请求头是否通过鉴权；
- 当前模型是否可用；
- 响应是否包含可读取的兼容文本。

检测请求只发送“请回复 OK”的最小提示词，不包含当前页面、节点分支、文件路径或导图 Markdown。

填写 API 密钥后，请求自动添加 Bearer `Authorization`。密钥输入框右侧的眼睛按钮可临时显示或隐藏当前密钥。附加请求头只接受字符串、数字或布尔值，并拒绝非法名称、嵌套对象和 CRLF 换行注入。

## 安全与隐私

- 只有用户点击发送或生成提案后，Markdown 才会发送到所选服务。
- 本地文字替换完全不联网。
- AI 修改必须经过本地解析、预览和用户确认。
- 预览后内容已变化时禁止应用旧提案。
- API 密钥保存在插件 `data.json` 中，不应提交到 Git、同步到公开仓库或发送给他人。
- 自定义接口仅允许 HTTP(S) 地址。
- 导图可能包含私人笔记、路径和远程图片引用；发送前应核对范围和大小。
- 使用第三方代理时，应确认其隐私政策、日志策略和数据保留方式。

## 操作示例

### AI 重整当前页面

1. 打开一个 `.mindmap` 文件。
2. 点击工具栏“询问 AI”，或按 `Ctrl/Cmd+Shift+A`。
3. 选择“AI 整理并重新生成（确认后应用）”。
4. 输入“按主题重新整理层级，合并重复节点，并保留所有重要信息”。
5. 生成并检查 Markdown 预览。
6. 点击“确认应用变更”。
7. 不满意时使用撤销恢复。

### AI 重整某个章节

1. 在目标节点上右键。
2. 选择“询问 AI（此节点及全部子节点）”。
3. 选择 AI 编辑模式并输入修改要求。
4. 确认范围、节点数和生成预览。
5. 应用后只会替换该节点分支。

### 本地把 A 替换为 B

1. 打开 AI 窗口。
2. 选择“本地文字替换（不调用 AI）”。
3. 查找填写 `A`，替换为填写 `B`。
4. 检查命中数和受影响节点数。
5. 点击“确认应用变更”。

### 恢复整页范围

在页面空白处右键，选择“询问 AI（当前页面）”。之后工具栏按钮和快捷键也会恢复整页范围。

## 故障排查

### 没有可选接口

至少启用一个配置，并填写有效接口地址和模型名称。本地文字替换不需要 AI 接口。

### AI 返回内容无法应用

确认回答以 `# 标题` 开头，且没有额外解释或 JSON。插件会优先提取 Markdown 围栏；解析失败时应调整提示词后重新生成。

### 提示预览已过期

生成预览后导图内容发生了变化。重新打开 AI 窗口或重新生成预览，避免覆盖新编辑。

### 请求过大

优先右键具体章节缩小范围。提高上限只改变插件侧预检，不能突破模型或代理自身的上下文限制。

### 401 或 403

检查 API 密钥、接口地址、代理要求的附加请求头和账户权限。

### 无法连接

确认服务地址使用 HTTP(S)，网络可访问，并且自定义代理支持 Chat Completions 请求格式。
