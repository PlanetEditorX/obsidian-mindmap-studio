# 测试策略

## 目标

### 图片粘贴目标与节点弹窗

- 单击新节点后粘贴外部图片，图片必须进入当前选中节点，即使旧节点仍保留浏览器焦点。
- 在“编辑节点内容”弹窗使用“+ 粘贴图片”、图片块内“粘贴剪贴板图片”和 `Ctrl/Cmd+V`，均应保存到仓库并写入该弹窗对应节点。
- 浏览器剪贴板读取权限不可用时，按钮应提示改用 `Ctrl/Cmd+V`，不能静默失败。


测试体系按风险分层，避免只依赖字符串快照或只验证构建成功：

1. **纯函数单元测试**验证输入边界和确定性转换。
2. **综合回归测试**验证模型、布局、导入导出、文章模式、搜索和样式契约。
3. **文档检查**保证所有源模块和声明存在 JSDoc，并确认关键说明文档存在。
4. **仓库检查**阻止临时分析目录、版本不一致、未引用样式和失效的主说明结构进入 Git。
5. **类型检查与生产构建**验证完整模块图和发布产物。

## 命令与职责

| 命令 | 主要范围 |
|---|---|
| `npm run test:unit` | 代码块布局、显示模式、语义位置、编辑器契约、文件名、图床和仓库清洁度 |
| `npm run test:regression` | 模型、节点树、布局、文章、导入导出、搜索、CSS 和版本约束 |
| `npm run test:docs` | 模块 `@file`、声明 JSDoc、关键文档 |
| `npm run test:repo` | 发布元数据一致性、README 非硬编码策略、必需文件、`.gitignore`、临时目录 |
| `npm run build` | TypeScript 与 esbuild 生产包 |
| `npm run verify` | 以上全部 |

## 单元测试边界

### 显示模式与阅读位置

覆盖：

- `outline` 不作为持久化启动模式，并回退到可见的导图、文章或通读模式。
- 大纲会话级、导图/文章/通读持久化规则。
- 目标节点到根节点的祖先回退顺序。
- 子导图消失时回到父导图挂载节点。
- 节点删除时恢复到最近仍存在的祖先。
- 磁盘记录规范化、重复节点去除和比例边界。
- 通读目录项与父挂载节点的语义锚点。
- 文章族切换时旧进度写回，以及多视图广播时延迟写入隔离。

### 文件名工具

覆盖：

- 路径分隔符、控制字符和非法字符。
- Unicode NFC 规范化。
- 空值后备、Windows 保留设备名、尾随句点和最大长度。
- 文件扩展名提取与后备值。
- 本地时间戳和默认标题。
- 图片 MIME 映射。

### 图床工具

覆盖：

- HTTP(S) 端点验证。
- Header JSON 类型、字段名和 CRLF 注入。
- multipart boundary、字段名、文件名、MIME 和二进制内容。
- JSON/文本响应载荷解析。
- 自定义字段路径、默认字段路径、数组索引和纯文本 URL。
- 图片 Blob SHA-256 的稳定性和不同内容区分。
- 删除端点/JSON 请求体模板中的 URL、哈希和删除令牌转义。
- 非 HTTP(S) 返回值拒绝。

这些测试不访问网络，也不依赖 Obsidian，失败时可以精确定位到数据转换层。

图片容灾专项测试还会确认：切换到可用镜像时使用权威内容块替换链路持久化新 `source`，并同步 `node.image` 兼容字段，避免重绘后恢复旧地址并重复弹出切换通知。

图片布局与编辑专项测试还会确认：图片块的同行/独占一行字段可规范化，文章和大纲会为连续同行图片创建 flex 行并移除单图自动外边距；同一图床按 SHA-256 命中上传缓存；Zipline、ImgBB、Freeimage.host 预设的响应路径和删除能力保持分离，旧 Zipline v3/v4 配置会迁移；远程删除必须经过最后引用扫描和显式删除能力，Zipline 缺失 ID 时会回查文件列表并复用当前 Token；完整节点编辑器通过窗口捕获、文本框回退和 `beforeinput` 使用与快速编辑相同的加粗、斜体、下划线及文字颜色快捷键，并验证 `Ctrl/Cmd+B` 的 `keydown` 与 `formatBold` 不会重复切换；图片预览尺寸保持较收敛上限。

### 文章编号

`tests/article-numbering.test.mjs` 覆盖：

- 八种编号样式的边界，第 9 级及更深标题不得重新循环为 `A.` / `（A）`。
- `E. → （A）/（B）` 下继续嵌套时，深层标题保留结构深度但不生成误导性的 A、B 前缀。
- 第 7、8 级同级字母序号超过 Z 后继续使用 AA、AB，避免同一父节点下出现重复编号。
- 正文、目录、通读和导出继续共用 `buildArticleNodeInfo()` 与 `articleNumberLabel()` 的单一解析结果。
- 末端正文带圈样式覆盖 Unicode 1/20/21/35/36/50 逻辑映射，确保 Markdown/Word 的 `①–㊿` 正确；文章、通读和 HTML 对第 1、20、50、51、67 项均输出正文数字与同一 CSS 圆环，字号、字重和首行基线一致且序号不截断。自动对齐时还要验证编号正文起点与圆点正文起点完全一致，圆圈右边缘与正文之间至少保留 0.18em 间距；为容纳圆圈宽度，圆圈中心可在普通圆点中心左侧最多偏移 0.15em。快速编辑专项必须确认圆圈额外下移量等于正文编辑框已有的 7px 顶部内边距，并且修正规则不得修改正文的 padding、margin 或水平 inset。
- 带圈样式可在第 8 级标题下面的第 9 级末端正文继续编号，而原“下一层文章序号”仍遵守八级边界。
- HTML 导出为全部带圈序号输出统一 `.circled-number` 结构；Markdown 与 Word 在 1–50 使用 Unicode、51+ 使用 `◯51` 可读回退；生成序号不得写回节点原文。

### 导图渐进渲染与文章目标窗口

`tests/incremental-render.test.mjs` 覆盖：

- 当前节点、兄弟、父节点、父级兄弟和祖先的确定性聚焦顺序。
- 当前视口、相邻视口和远端导图节点的空间优先级，且排序不修改原布局数组。
- 编辑器构造阶段不提前计算全树布局，真正进入导图模式后才执行权威布局。
- 文章模式首次只创建目标节点前后各约 5 KB 的真实章节 DOM；滚动接近边缘时按约 5 KB 扩展。允许入口阶段使用固定范围、非覆盖、非章节占位的轻量骨架，但不得重新引入零高度章节占位、隐藏舞台、整页覆盖层或后台全页 hydration。
- 文章语义位置恢复会先通过窗口控制器确保目标章节已挂载，再查询精确的标题或 `.mms-article-node[data-node-id]`；当前位置采集不得使用宽泛的文章页壳选择器。同文件目录点击必须直接聚焦节点，跨文件章节定位与父级返回必须传递稳定节点 ID。
- 入口骨架必须通过双动画帧先绘制再替换，快速连续重绘会取消旧帧；骨架期间的语义位置必须暂存，真实窗口挂载后恢复。边缘按钮的加载流光不得覆盖已渲染正文，`prefers-reduced-motion: reduce` 下不执行新增动画。
- 每次章节恢复必须使用递增令牌取消旧的 20 ms 重试、双动画帧和布局观察；活动目标要跨异步 `setOptions()` 重绘保留。图片、表格、代码或字体造成晚期高度变化时只能重新校准最后目标，滚轮、触摸、指针和键盘翻页必须立即取消自动校准。
- 文章族上下文刷新在目录层级、目录项和分页导航未变化时跳过当前文章重建。
- 向上补载必须按新增 `scrollHeight` 补偿 `scrollTop`；显式目标位置必须跳过旧位置恢复，文章运行时不得导入、初始化、读取或写入节点级持久缓存。

真实 Obsidian 桌面端仍需对大文件执行人工冒烟：打开 80 KB 以上文章时，首屏应只出现目标附近内容，点击后不能长时间卡死；连续滚轮、拖动滚动条和按 PageDown 应在接近边缘时平滑补载，向上补载不能改变当前段落的屏幕位置。分别从外部目录点击当前文件内章节、跨文件深层子章节，并快速连续点击三个目录项，最终必须停在最后点击的精确章节；等待 5 秒以及上方延迟图片完成后也不得再次跳转。再从子导图使用底部分页、顶部父级导航和 `Esc` 返回，确认定位到父挂载节点。还需在页面中部编辑文字、移动或删除节点，并检查图片、代码、表格、折叠和缩略导航。

### 代码块渲染

`tests/code-block.test.mjs` 覆盖：

- LF、CRLF、CR 与末尾空白逻辑行的行数计算。
- fenced code 中连续反引号的安全围栏长度。
- 节点显式设置、自动阈值、页面设置和全局默认值的优先级。
- 行号使用真实兄弟 DOM，重复增强不会生成第二个行号栏。
- 行号栏与代码栏共享字体、字号、字重、行高、字距和上下内边距的 CSS 变量。
- 导图、大纲、文章、通读均调用同一个宿主回调，并阻止 `code::before`、`data-line-numbers` 或光学基线常量回归。
- 导图节点中较高优先级的 `overflow: visible` 不会覆盖行号代码块的横向滚动。
- 导图节点只应用用户显式 `minHeight`，禁止把布局估算 `position.height` 固化为 DOM 最小高度。
- 折叠代码的 `<details>` 切换与异步 Markdown 高亮完成后都会请求重新测量导图布局。
- 权威内容块替换会清除旧版表格/代码镜像，删除后 `nodeContentBlocks()` 不会再次补回。

该测试不替代浏览器像素截图，而是锁定导致错位的结构性条件：相同计算度量、相同 `white-space` 策略、无软换行、无独立基线补偿。

### 内容块拖动与精确删除

`tests/content-block-drag.test.mjs` 覆盖：

- 同一节点内按稳定块 ID 重排，移动后顺序与代码兼容镜像一致。
- 代码块跨节点移动后，来源节点清除旧 `code` 镜像，目标节点重建对应镜像。
- 内容块可以追加到完全没有内容块的目标节点；跨节点移走最后一块时仅删除真正空白的非根叶节点。
- 完整节点编辑器 Enter 提交并关闭，Shift+Enter 保留换行，输入法组合状态不误提交。
- 编辑器块卡片和导图块都存在独立拖动手柄，导图的文字、图片、表格和代码接受跨节点放置；表格和代码手柄不得被内部滚动容器裁剪。
- 文章编辑模式不渲染内容块或整节点悬浮拖动手柄；工具栏和右键菜单提供作为块移动、作为节点移动、降为上一个节点的子节点、升为上一个节点的兄弟节点，后两项分别覆盖降级与提升后的树结构。
- 跨节点移走最后一个有效内容块后，真正空白的非根叶节点会自动删除；空文字占位块不会阻止删除，带子节点或附加元数据的来源节点仍保留。
- 导图表格单击不打开编辑器，双击才打开；文章表格继续使用双击编辑和表头列宽拖动。
- 导图右键从鼠标目标解析 `data-block-id`，“删除当前块”按节点 ID 与块 ID 精确执行。
- Markdown 导入将标题后的正文、图片、表格和多个 fenced 代码块写入同一节点的有序内容块，保持原始交错位置。
- Markdown 导入在富文本解析后移除常见中文/数字章节序号，跳过目录与顶部块锚点回链，并把其他块锚点退化为普通标签。
- 桌面 Markdown 图片解析依次尝试原相对路径、去掉 `assets/` 前缀和源笔记同目录文件名，覆盖笔记本身位于附件目录内的场景。


设置与文件浏览器性能专项测试覆盖：

- 连续多个设置保存请求只写入最后快照，所有等待方在该快照落盘后完成。
- 写入进行期间的新请求必须排在当前写入之后，任意时刻最多只有一个持久化回调运行；失败批次会拒绝等待方，后续显式保存可恢复。
- 文件浏览器规则签名忽略大小写、分隔符和排序等格式差异；单次扫描使用预编译谓词，不为每个条目重复解析后缀和目录列表。
- 插件 MutationObserver 只收集文件浏览器新增子树和 `data-path` 变化，并合并嵌套扫描根；普通文件保存及仓库生命周期回调不再触发文件树全量扫描。布局初始化和筛选设置语义变化仍会完整刷新。

## 综合回归测试

`scripts/test.mjs` 负责更宽的行为回归，包括：

- 文档创建、当前格式解析、规范化和序列化。
- 富文本、内容块、图片镜像和 Markdown 转换。
- 节点查找、移动、复制、粘贴、删除和历史记录。
- XMind 多画布导入、HTML/文章导出。
- 导图布局、碰撞处理和连接线。
- 文章层级、目录、编号、分页和连续阅读。
- 全局搜索索引和替换。
- 文件浏览器筛选。
- 关键 UI/CSS 契约与版本文件一致性。

该脚本包含大量源代码契约断言。新增功能时优先增加行为断言；只有 DOM 环境难以构造时才使用源码或 CSS 模式断言。

## 手动冒烟测试

自动化通过后，在独立 Obsidian 测试仓库至少验证：

1. 新建导图、修改中心节点、保存并重开。
2. 导图、大纲、文章和通读间双向切换，确认同一节点保持聚焦；关闭并重开后位置不丢失。
3. 撤销、重做、只读锁和多选操作。
4. 创建、打开、重命名、提取、合并和删除子导图；在子导图章节切换模式时确认自动打开正确文件，删除目标后确认逐级回退。
5. 在导图节点和文章正文分别连续粘贴多张本地图片，确认图片已插入时不会再出现“粘贴图片失败”或“保存同步出现异常”；启用自动上传后同时验证排程失败只显示警告且本地图片仍保留。可在开发者控制台临时让一次保存通知同步抛错，确认图片仍显示、保存会在下一任务重试且自动上传排程继续执行。
6. 使用测试图床验证成功、部分失败和无 URL 响应；在画布空白处右键执行“上传当前页面所有图片”，确认只弹出一次图床选择、已完整上传的图片会跳过、缺失镜像会补传。开启“中心节点标题同步文件名”后导入并替换整图，确认保存造成文件重命名时自动上传仍按设定延迟执行。
7. 重建索引、搜索、替换并重新打开结果。
8. Markdown/XMind 导入以及 Markdown/HTML/SVG 导出；桌面 Markdown 导入需确认“一、”“（一）”等原文序号不残留、目录块锚点不生成节点，并验证 `![[assets/公文/图片.png|L]]` 在源笔记位于同一附件目录时仍会复制并显示图片。另建超过八级的文章结构，确认第 8 级以下不再出现循环的 `A.` / `（A）`，正文、目录和导出显示一致。
9. 快速连续修改设置文本、展开设置分类和滚动文章后完全退出 Obsidian，再次启动确认最后状态已保存；在大文章重绘或打开弹窗时观察文件浏览器，确认不会因无关 DOM 更新持续闪烁或重复筛选。连续保存同一 `.mindmap` 时文件树不应全量刷新；展开大型目录或重命名文件时仅新增/改路径条目更新隐藏状态。
9. 在导图、大纲、文章和通读分别检查短代码、长代码、空行、Tab、CRLF 来源代码及 100%/125%/150% 缩放；确认行号逐行对齐、横向滚动正常且复制代码不包含行号。
10. 在导图中展开和折叠长代码，确认节点高度、相邻节点位置及连接线同步变化；手动设置最小高度后确认该下限仍有效。
11. 在非根子节点中完成文字编辑并退出，随后立即在画布空白处右键选择“收起所有节点”；等待文章上下文异步刷新后，确认所有非根分支仍保持收起，不会重新展开原焦点节点的祖先链。
12. 在节点较多且包含图片、表格或代码块的导图中连续点击不同节点，确认选择框变化不会触发整张导图持续向下漂移；内容真实增高时仍应只执行必要的碰撞重排。
13. 在导图和文章模式分别编辑表格内容、拖动列宽，确认保存后当前节点或阅读段落保持在原屏幕位置且画面不闪回顶部；随后在“编辑节点内容”中分别删除表格块和代码块，保存关闭、切换模式并重开文件，确认被删除内容不会恢复。
14. 在完整节点编辑器中输入两行文字：Shift+Enter 换行，Enter 保存并关闭；使用中文输入法时确认候选不会关闭。
15. 用内容块手柄在同一节点内调整顺序，再把代码块拖到另一节点的指定块前后和末尾；撤销、重做并重开文件确认归属和顺序。
16. 在文章模式用整节点手柄把同级 `C` 拖到 `A` 的下沿，确认顺序从 `A、B、C` 变为 `A、C、B`；再拖到章节中部，确认只有此时才成为子节点。
17. 在设置中分别选择“进入文章模式”的“默认锁定”“沿用进入前状态”和“记住上次文章状态”：前两者保持原有语义；记住策略下，先在文章中切为编辑，切到导图并改变导图锁状态，再次进入文章仍应编辑；文章中切为锁定后重复操作应仍锁定。
18. 打开插件设置，确认所有一级分类首次默认收起；展开多个分类后关闭并重新进入设置，确认只恢复这些分类。输入搜索词时匹配分类可临时展开，清空搜索后应恢复此前记忆，且重开设置不应记住搜索产生的临时展开。
19. 按住 Ctrl/Cmd 悬停节点右下角后切换到其他窗口并松开按键，再返回并移动鼠标：尺寸控制点应立即隐藏，普通点击节点可正常选中；重新按住 Ctrl/Cmd 后可拖动尺寸。
20. 分别右键文字、图片、表格和代码块执行“删除当前块”，确认只删除鼠标所在块。
21. 移动端或窄窗口下的主要工具栏和阅读布局。

## 回归失败处理

- 首先确认依赖是否通过 `npm ci` 完整安装。
- 单元测试失败：修复纯工具或补充边界说明，不要在调用方绕过校验。
- 综合回归失败：判断是行为变化还是测试过时；用户可见行为变化必须同步 `CHANGELOG.md`。
- 文档检查失败：补充具体 JSDoc，避免模板化注释。
- 仓库检查失败：删除本地分析产物，修复版本或文档结构。
- 构建失败：保留完整 TypeScript 错误，不要使用 `skipLibCheck` 以外的方式隐藏项目错误。

## CI 要求

GitHub Actions 和 GitLab CI 均从干净检出开始执行 `npm ci` 与 `npm run verify`。CI 通过后才能生成安装包。安装包必须只包含 `main.js`、`manifest.json` 和 `styles.css`。

### 图片失败、粘贴目标与批量自动上传

专项测试确认：

- 图片失败卡片会收集候选地址，并在导图、文章、通读和大纲渲染器中接入。
- 外部图片粘贴只使用事件开始时锁定的节点；旧文章焦点不能覆盖导图/大纲选择，目标消失时不回退。
- 多张到期图片按文件批处理并串行执行；上传结果通过 `applyImageUploadPatches()` 合并到最新文档，保留上传期间的文字编辑和兄弟节点。
- 过期本地路径任务被拒绝，自动上传路径不得调用整文档 `refreshOpenMindMap()`。
- 文章上一篇、下一篇、返回上级和阅读完成按钮不包含会触发悬浮提示的属性。
