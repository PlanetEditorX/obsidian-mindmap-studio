# 文章文字悬浮提示修复

## 问题

文章和大纲中的可行内编辑文字在未编辑时就带有 `role="textbox"` 与 `aria-label`。Obsidian 会把这些辅助标签显示为鼠标悬浮提示，因此章节标题、正文段落等文字上会出现不必要的提示。

## 修复

- 渲染静态文字时只保存内部编辑标签，不写入 `aria-label` 和 `role`。
- 用户点击或程序启动行内编辑时，临时添加文本框语义与辅助标签。
- 编辑结束、切换只读状态或重新渲染时移除这些属性。
- 保留空文字占位符、行内富文本编辑、格式工具栏及键盘辅助信息。

## 行为

普通阅读状态下，鼠标停留在章节标题、正文段落、文章标题、导图标题或大纲节点文字上，不再显示编辑用途的悬浮提示。进入编辑状态后，屏幕阅读器仍可获得对应编辑标签。
