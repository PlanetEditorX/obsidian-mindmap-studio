# 特殊功能实现说明

## 中心节点与文件名同步

“中心节点标题同步文件名”默认开启。插件只在本次保存检测到中心节点标题实际变化时，以中心节点纯文本标题生成新的 `.mindmap` 文件名，并自动处理非法字符和同名序号；调整表格列宽、样式、任务或其他正文内容不会顺带修正一个原本就与标题不一致的文件名。重命名子导图会同步更新父导图节点保存的 `submap.path` 与标题；重命名父导图会同步更新直接子导图的 `navigation.parentPath` 和 `parentTitle`，保持双向导航完整。

## 节点编辑手势

普通节点双击文字或中间留白区域进入快速文字编辑。双击距节点边缘约 18 px 的边缘带会直接打开“编辑节点内容”完整面板；不再依赖四击或延迟判定。导图和大纲中的右键菜单、`F2` 继续打开完整节点编辑器；文章编辑模式会将对应入口显示为“编辑当前内容”，直接聚焦章节标题或正文。仅含图片、表格、代码等内容而没有正文的文章节点显示“添加正文”，并创建临时正文输入行；文章阅读模式不显示编辑入口。文章节点获得焦点后，非根节点下方和右键菜单均提供“添加同级、添加子节点、作为块移动、作为节点移动、降为上一个节点的子节点、升为上一个节点的兄弟节点、删除、更多”等操作，根节点只保留合法操作；文章不显示任何悬浮拖动按钮。“作为块移动”从当前编辑或右键命中的稳定内容块开始；选择模式中，目标块上半部表示插入前、下半部表示插入后，点击节点空白区域才追加到末尾，因此同一节点内也能排序。如果来源节点因此变成真正空白的非根叶节点，会沿用现有规则自动清理。“作为节点移动”完整保留来源节点的内容、子树和元数据，并固定插入到随后点击目标的后方。“降为上一个节点的子节点”把当前节点移动到同级前一节点之下；“升为上一个节点的兄弟节点”把当前节点提升到父节点的同级并紧跟父节点。选择目标期间会显示提示、可用目标和非法目标，按 `Esc` 或提示栏关闭按钮可取消；根节点不能作为普通节点移动，节点也不能移到自身或自己的后代。操作按钮不会先触发行内编辑失焦，因此新建的空白节点也可以立即删除。删除文字块全部内容并退出编辑时，该文字块会自动移除；仅当它是节点唯一内容时保留为空文字块，方便继续输入。

完整节点编辑器中，Enter 会立即校验、保存并关闭窗口；Shift+Enter 在文字块或备注中保留换行。处于中文等输入法组合输入状态时，Enter 只确认候选，不会误关闭窗口。

使用 `Enter` 或 `Tab` 新建节点后，编辑器会保持新节点的快速输入焦点；创建该节点的按键释放不会再导致输入框立即退出。

在可编辑导图中选中节点后按 `Space` 可直接进入快速内联编辑；阅读模式下 `Space` 仍用于展开或收起节点。

Markdown 导入会识别标准图片语法及 Obsidian 图片嵌入语法，例如 `![[Pasted image 20260622014655.png]]`，并生成可预览、可编辑、可识图的图片内容块。

导图中的代码、图片和表格会在浏览器完成实际渲染后重新测量尺寸。折叠或展开代码时，相关分支和同级节点会按新的实际高度自动重新排版，并以平滑过渡移动。

## 全局搜索替换

全局搜索只匹配节点自身的可搜索内容，不会因为父节点、层级路径或文件名包含关键词而返回无关子节点。结果保留原始 `nodeId`；替换全部或替换单条结果时，插件重新读取对应导图并按该 ID 定位真实节点，再替换全部文字内容块和备注；富文本样式会随文本变更重算并保留。替换内容会写回节点的 `content` 数据，保存后重新读取校验，并同步已打开的导图编辑器；只有实际写入变更时才显示替换成功。结果标题支持自动换行，长节点文字不会被单行省略截断。

## 题库练习与错题回顾

先在“文件与资源”中设置题库文件夹。该文件夹及其子目录中的导图会增加“答题”模式：工具栏或节点右键可新建/编辑题目节点，支持选择题、判断题和大题、图文题干、选项、答案、解答与标签。题图可由 AI 转成题目，并可继续检索原题；未检索到可验证来源时，AI 会补齐缺失答案和解答，保存前仍可人工校对。

答题模式默认随机排列题目，也可在设置中改为按导图顺序。单选、多选会依据参考答案中的选项标签自动判题；判断题固定为“正确 / 错误”两项；大题按规范化后的文本与参考答案精确比对。题干只显示一次，选项采用整行可点的原生单选/复选控件，选中后会立即高亮。解析会按“前置说明一段、A/B/C/D 各一行、D 项后的总结与最终答案一段”显示；“综上所述，正确选项为……”会作为完整结论独立于 D 项，不会再被拆成多个零散段落。提交后可查看答案和解析，点击“下一题”继续；最后一题显示“结束答题”，进入完成页而不会回到第一题。每次作答都会保存次数、正确次数和最后练习时间；答错自动标记为“错题”，切换“错题本”即可只回顾错题，后续答对会自动移出错题本。

## 连线宽度精度

“主题与外观”和插件设置中的起始粗细、末端最细宽度统一使用 `0.05 px` 步进。内置主题可使用 `4.2 px`、`1.2 px` 等一位小数的连线宽度；应用主题时不会被浏览器的数字输入校验拦截。

## 节点右下角控制

默认状态下，节点右下角保留折叠/展开和下级数量按钮。启用默认的“按住 Ctrl/Cmd 调整大小”后，普通点击节点不会显示尺寸控制点；只有在按住 `Ctrl`（macOS 为 `Cmd`）并悬停节点时，才会隐藏该节点的数量按钮并在相同右下角位置显示尺寸控制点。移开鼠标或松开按键后立即恢复数量按钮。

## 图片尺寸与批量折叠

### 节点图片粘贴

导图和大纲中的外部图片粘贴不读取旧 DOM 焦点，只使用粘贴瞬间的当前选中节点。完整“编辑节点内容”弹窗支持按钮读取剪贴板图片，也支持直接 `Ctrl/Cmd+V`；图片先保存到仓库，再写入当前节点并进入现有自动上传排程。


完整编辑节点中的每个图片块都可设置显示宽度和高度（20–2000 px）；留空时保持各模式默认尺寸，高度留空时由图片自身比例决定。导图、大纲和文章会使用同一尺寸设置。导图工具栏的“展开/折叠全部子项”会在全部展开和全部折叠之间切换；在画布空白处右键可直接选择“展开所有节点”或“收起所有节点”。

## 1. 四种显示模式共享同一份数据

导图、大纲、文章和通读模式不是四个副本。它们都读取 `MindMapDocument.root`：

- 导图模式改变节点层级后，大纲和文章立即反映。
- 大纲模式修改标题后，导图节点立即更新。
- 文章模式编辑正文后，导图和大纲使用同一文本。

模式切换只改变渲染方式，不创建或转换文件。

### 大型导图增量加载与文章窗口渲染

大型导图进入或结构变化时，插件在导图模式真正需要时一次计算完整布局以保证连线正确；单次计算缓存每个节点的子树高度，深层链式结构不会重复遍历。节点 DOM 仍按当前关系链、当前窗口、相邻窗口和其他区域分帧挂载。

文章模式使用另一套更稳定的目标窗口方案。文章上下文准备完成后先建立轻量章节顺序，只挂载当前选中或导航目标前后各约 5 KB 的真实章节；滚动接近窗口边缘时再按约 5 KB 扩展。首次进入正文或目录跳转时先显示固定范围的轻量骨架，浏览器完成绘制后再替换为真实目标窗口；骨架不覆盖已有正文、不模拟章节高度，也不会在隐藏舞台补全整页。边缘扩展只在加载按钮显示反馈：按钮文字使用 Flex 双轴居中，实际加载时仅保留按钮内部流光，不再运行额外的圆角边框动画；新加入的真实章节短暂淡入。向上增加前文后会按新增高度补偿滚动位置，因此当前段落不会被顶走。目标不在当前窗口时，语义位置恢复会先重置到目标附近，再查询真实 `.mms-article-node`；骨架期间收到的位置先暂存，真实窗口挂载后再执行。系统减少动态效果时全部新增动画被跳过。运行时仍不读写 `cache/article-render-cache.json`。

文章上下文尚未完成时不会提前绘制当前物理文件正文，而是按已保存的落地模式显示目录骨架或正文骨架。显式章节或父级挂载目标的优先级更高：存在 `filePath + nodeId` 时，即使全局配置为“显示目录”，本次导航也必须直接落到正文目标，不能被异步上下文覆盖回目录。目录和正文之间的切换是对称的：进入章节使用正文骨架，返回目录使用目录骨架且从顶部落地。跨文件目录目标会在新视图创建前排队，新编辑器先取得精确节点再读取父子上下文，因此不会先显示父章节编号与子文件根标题的临时组合。

物理文件切换会取消旧文件遗留的阅读恢复、动画帧和布局观察，并在同一次 `setDocument()` 中应用新文件路径选项，避免旧事务向新页面写入页首位置。返回父导图时先验证父节点 ID；若旧元数据中的 ID 已失效，则按当前子导图路径在父导图中反查真实挂载节点。

顶层目录中属于当前物理文件的章节会直接调用编辑器聚焦链路：先从纯目录页切换到正文，再围绕目标生成窗口；跨文件章节仍传递 `filePath + nodeId` 打开目标文件。当前位置采集只扫描文档标题和真实文章章节，不扫描文章页壳。显式跳转会建立“最后一次导航独占”的可取消事务，新目标会作废旧定时器和动画帧；短时 `ResizeObserver` 在图片、表格、代码或字体晚到时维持同一目标，用户发生滚轮、触摸、指针或键盘翻页输入后立即停止自动校准。

文字行内编辑按 Enter 或失焦提交时，只更新当前节点的权威内容块、自动保存状态和必要布局测量。保存后的异步文章族上下文刷新若没有改变目录层级、目录内容或分页导航，只更新跨文件阅读快照，不再重建当前页。新增、删除、移动节点或改变主题等结构性操作仍执行完整渲染。

## 2. 运行调试模式

插件设置“管理配置 → 调试模式”用于收集可复现的导航时序。开启后只在内存中记录本次会话，覆盖点击、双击、右键、按键、滚轮/滚动、文件打开、活动视图变化、目录和父级导航、文章上下文、目标窗口、语义滚动事务及异常。日志最多保留固定数量的最新事件，并对高频滚动节流。

日志不会保存文章正文、输入框值、密钥或 AI 请求正文。可编辑区域的普通字符按键统一记为 `[text]`，DOM 目标只保留类型、类名、节点 ID 和文件路径等定位字段。复现后执行命令面板“复制 MindMap Studio 调试记录”，得到带会话元数据的 JSONL；关闭开关或重启插件会清空。

## 3. 全局显示模式记忆

用户点击导图、大纲或文章模式后，插件保存 `globalDisplayMode`，并通知所有已经打开的导图切换。之后打开父导图、子导图或其他文件，都会使用同一模式。

设置中的“显示哪些模式”只控制按钮是否可见，不会删除数据；至少保留一种模式。设置页一级分类默认全部收起，并在插件配置中记住用户手动展开的分类；搜索只临时展开匹配项。

## 4. 阅读锁

阅读状态按文件保存。进入阅读模式后禁止：

- 新增、删除、编辑和拖拽节点。
- 修改尺寸、样式、表格、代码。
- 粘贴和结构重组。
- 撤销、重做写操作。

文章阅读页点击正文不会选中节点或显示编辑边框；选中反馈只在编辑模式启用。进入文章模式可选择始终锁定、沿用当前模式状态或记住文章模式自己上次的状态。记住策略独立于文件级锁和其他显示模式，文章内最后一次锁定或编辑会成为下次进入文章的状态。

仍允许：

- 搜索和定位。
- 缩放、平移。
- 打开链接和子导图。
- 查看图片。
- 临时展开折叠。
- 切换四种显示模式。

## 5. 子导图

### 创建

对节点执行“创建子导图”后：

1. 在父导图资源目录下创建独立 `.mindmap` 文件。
2. 父节点写入 `submap.path`。
3. 子文件写入 `navigation.parentPath` 和 `parentNodeId`。
4. 新建子文件保留标准初始结构，中心节点下默认创建“主题 1”和“主题 2”两个子节点。
5. 保存父文件后打开子文件。

### 进入

导图模式中，关联子导图的整个节点都是进入区域，用户不需要精确点击文字。拖拽、右键、折叠按钮和内部链接仍保留自身行为。

大纲和文章模式中，节点标题本身是文字链接，不显示重复的“进入子导图”按钮。

### 提取子导图 / 合并子导图

在编辑模式下，右键点击任意非根节点 → 「提取为子导图」，可将该节点及其全部后代移入一个独立的 .mindmap 文件，并从当前导图中删除该节点。新文件自动放置在「资源文件夹 / 父导图名 /」目录下，并记录父导图导航信息。

在子导图中，右键点击根节点 → 「合并回主导图」，可将子导图的所有子节点合并到父导图中对应的链接节点下，清除链接标记，删除子导图文件，并自动导航回父导图。

### 返回

子导图左上角显示固定悬浮面包屑：

```text
← 父导图 › 当前导图
```

它不随画布缩放或平移，也不改变中心节点外观。返回后通过 `parentNodeId` 定位来源节点。

## 6. 文章编号

文章编号有三种节点级状态：

- **自动**：字段缺失时的默认状态。根据父节点的有效文章层级和当前同级标题结构自动推导。
- **关闭**：`articleNumberingMode: "none"`。普通节点不显示编号，也不占用该文章层级的序号；中心节点关闭时，当前导图内所有章节编号与末端自动序号都关闭。若当前文件是顶层总目录，该状态继续继承到全部挂载子导图。
- **手动层级（自定义最高层级）**：`articleNumberingMode: "manual"` 配合 `articleNumberingLevel: 1–8`。覆盖当前节点或中心节点子树的最高可见文章层级，但不强制孤立末端节点成为标题。

编号样式：

```text
1  第一章
2  第一节
3  一、
4  （一）
5  1.
6  （1）
7  A.
8  （A）
```

`buildArticleNodeInfo()`、`resolveArticleNumbering()` 与 `isDocumentArticleNumberingDisabled()` 共同生成有效层级和显示状态。普通手动标题的后代从手动层级加一继续推导；中心节点手动层级直接成为一级子节点的层级。中心节点本身从不显示编号，因此根节点保存的 `none` 会被解释为当前导图的整页编号开关：正文、目录、通读、导出以及子文章页标题统一隐藏编号，但标题结构、目录相对层级和阅读位置不变。顶层总目录关闭时，该状态沿挂载关系继承到整本文章族；子导图单独关闭时只影响该子导图及其后代。普通非根节点的 `none` 仍只跳过该节点。编号样式只定义到第 8 级；第 8 级标题下面仍可继续建立更深结构，但这些后代不再循环复用 `A.` / `（A）`，避免出现 `E. → （B） → A.` 的层级错觉。同一级字母序号超过 Z 后继续使用 AA、AB，而不是重新从 A 开始。

标题判定仍以文章结构为准：有子节点或子导图链接的节点是自然标题；同一父节点下只要存在自然标题，其他同级末端节点也作为同级标题，从而保证第一个“词义”得到“（1）”。只有一个孤立末端节点时，即使配置了手动最高层级，也仍作为正文。

同一父节点下的序号按**有效文章层级**分别计数。例如手动 3 级节点会依次得到“一、”“二、”，手动 5 级节点会独立得到“1.”“2.”。关闭编号的节点不会推进任何计数器。

末端正文达到设置阈值后，还可以选择独立的“带圈数字”样式，而不是使用标题的下一层编号。文章正文、通读和 HTML 导出对第 1 项起就统一使用正文数字配合 CSS 圆环，不再直接显示可能触发字体回退的 `①–㊿`，因此第 1–50 项与第 51、60、70 项保持相同字重、外框尺寸和首行基线，也没有 50 项的软件上限。在自动对齐模式中，带圈编号正文与普通末端圆点正文保持同一首字起点；较宽的圆圈会略向编号区内收，并在右侧预留可读间距，避免圆圈贴住正文。快速编辑只把圆圈按编辑框现有的 7px 顶部内边距向下补偿，不改变正文输入框的尺寸、内边距或文字起点。顶格模式不额外加入上级标题缩进。带圈样式不占用标题层级，位于第 8 级标题下面的更深末端正文也可继续编号。Markdown 和 Word 等无 CSS 导出仍在第 1–50 项使用 Unicode `①–㊿`，并对第 51 项以后使用 `◯51` 形式，保证在不支持 CSS 的环境中仍可识别。所有生成序号只存在于展示层，不会写回节点原文。

要实现成语笔记中的“一、相得益彰 / （一）词义 / （二）易混淆成语”，只需把中心节点的最高层级设为 3；要改成“1. / （1）”，把中心节点最高层级设为 5。中心节点编辑窗口和“主题与外观”提供同一组设置。

## 7. 文章目录

当当前文件是最上层脑图并且存在子导图时，文章模式生成目录页，并递归读取整个导图族：

- 普通子节点作为同文件目录项。
- 子导图节点作为可跨文件打开的目录项。
- 更深层子导图继续递归。
- 循环引用通过已访问路径集合停止。

点击目录项会打开对应文件、保持文章模式并定位节点。跨文件目标在视图切换前预排队，首个真实文章窗口直接使用目标章/节编号；同文件目标直接切换正文。章节返回目录也显示轻量目录骨架，并清除正文阅读锚点后从目录顶部进入。

文章模式保持“纯目录页 / 原始文章”二选一：进入原始文章后不在正文顶部重复插入目录。顶层导图每次进入文章模式或重新打开文件时都优先显示目录；“显示原始文章”只在当前进入周期内生效，不写入长期落点。目录最大层级优先读取当前 `.mindmap` 文件的 `view.articleTocMaxDepth`；未设置时跟随插件全局 `articleTocMaxDepth`。同一覆盖值也用于通读模式，可在“主题与外观 → 文章编号与目录”中选择“跟随插件设置”或手动指定 1–8 层。

文章分页与目录展开使用不同集合：目录仍递归展示当前页内部的章、节和正文标题；分页只保留当前物理 `.mindmap` 页面在相同父级、相同结构层级下的兄弟子导图。`resolveArticleSiblingPages()` 会跳过带 `nodeId` 的页内标题，因此“第一章 世界”的下一篇是“第二章 中国”，而不是当前文件中的“第一节 世界历史”。嵌套节级页面同样只在所属章节下的兄弟页面间切换。子导图页面标题使用父目录项编号加当前根节点标题，编号部分不可直接编辑，根标题仍可原位编辑。

通读模式在全书目录后连续渲染各级子导图。最顶层导图只作为书名和目录结构来源，不再重复显示为正文；目录按照相对树结构缩进，编号层级与目录层级分开计算。即使最高编号层级从第 5 级 `1.` 开始，一级标题在目录中仍按第 1 层显示，不会被“目录最大层级”误过滤。每个子导图的正文标题按 `filePath + nodeId` 直接复用目录中的章节层级和编号；编号与富文本标题分别渲染，标题刷新不会再删除编号。目录跳转锚点编码完整文件路径，中文名称相近的章节也不会互相跳错。 当前从某个子导图进入通读并修改该文件编号方案时，刷新过程直接复用尚在编辑器中的最新文档，因此目录和正文会同步更新，不受自动保存时序影响。

文章和通读模式都会在右下角提供悬浮的“回到顶部”按钮。按钮默认隐藏；可在设置中通过 `0–100%` 滑块或直接输入百分比设定显示阈值，例如 `50%`，达到对应阅读进度后才显示。点击后仅平滑滚动当前文章视图到顶部，不会切换模式或影响阅读进度。

## 8. 阅读缩略导航图

文章和通读模式可在右侧垂直正中心显示结构缩略导航图。它显示当前页面的最高和次高两个结构层级：页面以“第一章、第一节”为例时，章节与小节均会出现；最高层级使用粗条，次高层级使用细条。导航图没有背景和横向底条，直接悬浮于阅读页边缘；仅允许纵向滚动，防止出现底部横向滚动条。默认刻度为较大的短条；鼠标在某一位置移动时，最接近的短条会略变长，上下相邻短条按距离依次缩短，移开后平滑恢复默认长度。鼠标悬停刻度会显示对应章节名，例如“第五章 生活”。当前阅读类别显示为深色，页面滚动时深色条会随当前类别切换。点击短条即可精确滚动至相应位置。导航图使用与文章目录相同的最大层级设置，不显示超出“目录最大层级”的条目。导航图会在文章页面右侧留白不足时自动隐藏，例如打开侧边栏后正文已接近右边缘；窗口空间恢复后会自动显示。无操作 10 秒后导航图淡出，鼠标移到右侧中部区域即可再次显示。插件设置“文章/通读缩略导航图”控制全局默认开关；“主题与外观 → 阅读缩略导航图”可为当前 `.mindmap` 选择跟随插件设置、显示或隐藏。

## 9. 文章折叠、末端圆点与文件浏览器筛选

插件设置提供三个互不影响的开关：

- **文章标题可折叠**：文章和通读模式中，带有后续子级内容的标题在鼠标悬停或键盘聚焦时才显示内联向下箭头；点击后箭头变为向右，并仅隐藏该标题所属的正文和更深层子标题，表现与 Markdown 标题折叠一致。通读模式的每一章书章节标题也支持同样的折叠操作。
- **末端正文标识、序号与对齐**：没有文章编号的末端节点正文前可显示实心圆、空心圆、实心方块或短横线，并可指定颜色；达到兄弟节点阈值后可转为下一层文章编号或带圈数字。带圈数字在文章、通读与 HTML 中从第 1 项起统一由 CSS 绘圈；Markdown 与 Word 在 1–50 使用 `①–㊿`，51 以上使用可读回退。颜色留空时跟随当前文章主题强调色。标识开关、转序号与正文对齐彼此独立，对齐可选择顶格或自动缩进至上级标题下。插件设置提供全局默认值，当前页面“主题与外观 → 阅读样式”可单独覆盖，文章与通读共用；只读状态下仍可修改。
- **文件浏览器筛选**：相关控件统一位于插件设置的“文件与资源”分类。可隐藏当前资源文件夹，也可启用自定义规则，按后缀（如 `png, jpg`）或文件夹名称/仓库相对路径（如 `附件`、`项目/缓存`）隐藏 Obsidian 左侧文件浏览器项目。该功能只改变界面可见性，不会删除、移动或修改仓库文件，也不影响搜索和链接。筛选观察器会忽略文章渲染、弹窗和普通文件保存等无关变化；布局初始化或筛选设置的实际语义改变时才完整刷新，日常展开目录、创建或重命名文件只筛选新增或改路径的局部条目。每批扫描只编译一次规则。
- **设置职责归类**：新文件名前缀、中心标题同步文件名、保存位置和资源路径统一位于“文件与资源”；默认布局、打开时适应画布、任务进度和嵌入预览高度位于“视图与阅读”；默认明暗模式及代码折叠、行号、主题和自动阈值位于“主题与外观”；节点编辑器位置与双指手势位于“编辑与交互”。旧版“代码行为”分类会迁移到“主题与外观”，不改变已有设置值。

## 10. 节点文字对齐与尺寸

插件设置“连线与分支”提供全局“分支外观”，可选择圆润卡片分支（曲线）或圆角分支（折线）。当前 `.mindmap` 文件可在“主题与外观”中单独覆盖；该窗口采用加宽的双列纵向卡片布局，左列依次显示画布、连线和代码设置，右列依次显示节点、文章编号与目录设置，避免不同高度卡片造成大片空白。窄屏自动切换为单列，恢复全局默认后重新继承插件设置。

节点文字支持左、中、右对齐：

- 插件设置提供全局默认值。
- 节点样式可以单独覆盖。
- 导图显示和 SVG 导出使用同一对齐规则。

节点尺寸支持：

- 右下角尺寸手柄拖动。
- 编辑弹窗精确填写宽度和最小高度。
- 双击手柄或右键恢复自动大小。
- 宽度缩小时文字自动换行。
- 高度是最小高度，内容不会被裁切。
- 所有导图节点都有 36px 的全局最低高度；即使节点文字为空，也会保持可见、可选中和可编辑的节点形态。
- 文章编辑模式会为新建的空白末端节点生成占位编辑行，右键“添加子节点”后可立即输入，无需切回导图模式。

## 11. 富文本

文字块支持字符范围级别的：

- 加粗。
- 斜体。
- 下划线。
- 颜色。
- 标准 Markdown 超链接：任意输入、粘贴和导入的 `[链接文字](https://example.com)` 都会识别为可点击链接；编辑时保持原地编辑，导出仍使用标准 Markdown 链接。

编辑过程中，`reconcileRichTextAfterEdit()` 根据公共前缀和后缀迁移旧样式，减少用户插入或删除字符后格式全部丢失的问题。快速行内编辑和“编辑节点内容”完整面板共用全局加粗、斜体、下划线快捷键配置；选区存在时两处均直接切换对应样式，并阻止按键继续触发结构操作。完整面板会对同一次 `Ctrl/Cmd+B` 的键盘事件与 Chromium `formatBold` 输入事件去重，避免连续切换两次后看起来未生效。

## 12. 有序混合内容

文章模式会识别右键所在的具体内容块。“在此块后插入文字”把新文字块插入到代码、表格或文字块之后，并直接聚焦新段落，不再回到第一个文字块。正文文字块右键还可在“首行两格”和“顶格”之间切换段落缩进；设置按文字块保存并同步到通读模式。

节点内容不再固定为“文字加一张图片”，而是有序内容块：

```text
文字 → 图片 → 文字 → 图片
```

支持纯图片节点。图片块可选择“与相邻图片同行”或“独占一行”：连续同行图片保持内容块顺序并自动换行，块级图片占据完整行；导图、大纲和文章共用该字段。`syncNodeContentFields()` 会同步文本摘要、单段富文本和首张图片字段，供搜索、静态预览和导出复用。

编辑模式下，每个导图内容块左上角都有独立拖动手柄。拖到同一节点其他块的上方或下方可调整顺序；拖到另一节点的具体块前后或节点内容区末尾，可跨节点移动整个文字、图片、表格或代码块。该操作只移动块，不会触发整节点拖拽，并通过同一撤销历史保存。完整节点编辑器中的块卡片也提供手柄用于当前节点内排序。

右键菜单根据鼠标所在的稳定块 ID 操作。文字、图片、表格和代码均显示“删除当前块”，不会退化为删除整个节点或误删同节点其他块。

导图编辑模式的文字、图片、表格和代码通过内容块左侧手柄开始拖动；表格和代码使用位于滚动区外部的结构化块壳层，手柄不会被裁剪。拖到具体块的上半区或下半区可精确前后插入，拖到节点空白区域会追加到末尾，完全空白的节点也可直接接收内容块。文章编辑模式不显示悬浮拖动手柄，改用工具栏和右键菜单中的四项明确移动规则。跨节点移走最后一个有效块后，只会自动删除真正空白且不承载子节点或附加元数据的来源叶节点，残留的空文字占位块不会阻止清理。

## 13. 表格与代码

表格支持：

- 手工创建。
- 粘贴 Markdown 表格。
- 把直接子节点转换为表格。
- 列对齐设置。
- 在文章编辑模式双击表格打开单元格编辑器。
- 在导图模式仅双击表格才打开单元格编辑器，单击不会进入编辑。
- 拖动表头分隔线调整相邻两列宽度；一侧增宽时另一侧等量缩窄，表格总宽度始终适配文章页面。列宽按比例渲染，窗口变化后自动缩放；长内容在单元格内换行，不产生横向滚动条。释放鼠标只提交列宽数据，不重建整篇文章 DOM，也不触发延迟文章族上下文刷新；列宽写入内容块，重新加载后恢复，并同步用于导图和大纲。

代码块支持语言名称（包含 Nginx）、默认折叠、行号，以及 Obsidian、GitHub、Monokai、Dracula 样式，并继续使用 Obsidian Markdown 渲染器生成语法高亮。行号不再放入 `code::before` 伪元素，而是在同一 `pre` 中创建独立、不可选中的真实 DOM 行号栏；渲染器先读取高亮代码的实际字体、字号、字重、行高、字距和代码块内边距，再通过 CSS 变量同时应用到行号栏与代码栏。两栏均使用 `white-space: pre`，禁止软换行并共享相同的逐行节奏，因此不同主题、缩放比例和导图/大纲/文章/通读容器不会再依赖模式专用的像素或 `em` 补偿。代码显示设置按节点、当前页面、插件全局依次覆盖；节点或页面选择“跟随”时自动使用下一层设置。全局可设置行数阈值：不超过指定行数时保持展开，超过指定行数时自动显示行号；节点显式设置仍可覆盖。详细实现和回归范围见 [代码块渲染说明](CODE_BLOCK_RENDERING.zh-CN.md)。

## 14. 图片保存与图床

粘贴图片时先保存到当前导图附近的资源目录。用户可以配置多个通用图床：

每个图床使用独立的折叠卡片，默认仅显示名称和启用状态；点击箭头后再展开 API、鉴权、返回字段、自动上传和连通性检测配置，避免多个图床同时占满设置页。

卡片顶部提供维护中的预设：

- Zipline（默认）：上传字段 `file`，读取 `files.0.url` 与 `files.0.id`，删除时调用 `DELETE /api/user/files/{id}`；历史图片缺少 ID 时通过当前 Token 查询 `/api/user/files`，按 URL 或文件名补回。旧 Zipline v3/v4 配置自动迁移。
- ImgBB：上传字段 `image`，读取 `data.url` 和唯一 `data.delete_url`，最后引用删除时访问该秘密删除链接。
- Freeimage.host：上传字段 `source`，读取 `image.url`；公开 API 不返回匿名删除链接，因此预设不启用自动删除。
- 自定义：保留全部请求、响应和删除模板字段供其他服务使用。

- `POST` 或 `PUT`。
- `multipart/form-data` 或原始二进制。
- 自定义请求头。
- 自定义文件字段名。
- JSON 响应中的 URL 路径。
- 加载优先级，数值越小越优先。
- 可选删除令牌响应字段、删除 API、GET/DELETE/POST 方法和删除请求体模板；删除请求与上传请求始终共用同一份当前请求头。

连接测试上传 1×1 PNG，用于确认请求和 URL 提取配置；若图床提供删除接口，测试图片进入 1 分钟延迟清理队列，避免连通性测试留下垃圾文件。正式上传前会计算图片二进制 SHA-256，并按“图床 ID + SHA-256”查询持久化缓存：命中时直接复用已有 URL 和删除令牌，不再次上传；同一图片发送到另一个图床时仍会为该图床独立上传。缓存最多保留最近使用的 1000 条。

## 15. 自动上传和本地删除安全条件

自动上传默认在粘贴或截图后 1 分钟执行，可设置为 0–120 分钟。延迟期间图片仍保留在本地，可直接用于 AI 识图；重新打开导图时会根据本地图片时间补齐未完成的上传，到期立即上传。上传成功后，节点渲染、点击放大图片和 AI 识图会优先使用优先级最高的可达 HTTPS 图床地址；失败后再尝试下一个图床地址，最后按设置回退到本地副本。只有满足以下条件才删除本地文件：

1. 所有选中图床均上传成功。
2. 远程地址已写回节点。
3. 当前导图已成功保存。
4. 本地文件仍位于仓库中。
5. 没有其他节点继续引用该本地资源。

任何图床失败都保留本地文件。本地副本因上传成功而删除时，远程图片不会删除，因为节点仍依赖该远程来源。

当用户删除图片块时，可选的“最后引用删除时同步清理图床”流程会先保存当前打开视图，再扫描当前文档和仓库中其他 `.mindmap`：只要仍有相同 `contentHash` 或任一相同远程 URL，立即保留图床文件。确认最后引用已删除后，任务进入 1 分钟持久化安全队列；到期前撤销恢复图片时，最终复查会取消删除，插件重启后也会恢复队列。只有对应图床预设或自定义配置明确提供删除能力才会发送请求；Freeimage.host 公开 API、缺少 Zipline 文件 ID、文档无法安全解析或服务返回失败时都保留远程图片并提示。直接在文件系统中手工删除本地资源文件不会被当作远程删除指令。

## 16. 图片镜像自动容灾

每个图片块可以有多个远程镜像。候选顺序从当前源开始轮转：

```text
当前图床 → 后续镜像 → 前序镜像 → 本地回退
```

加载错误或超时后自动尝试下一地址。成功后：

- 通过权威 `content` 图片块更新 `source`，并同步 `node.image` 兼容镜像。
- 记录成功时间。
- 保存文档。
- 旧地址继续保留在镜像列表中。

点击图片进入放大预览时，预览页会列出当前图床、这张图片已经上传的其他图床镜像以及本地副本。点击来源按钮只切换当前预览，不修改节点保存的主图片地址；加载失败的来源会显示错误状态。预览窗口限制为约 `86vw × 82vh`、最大 `1400 × 900 px`，比旧版更适合在 Obsidian 内并排查看上下文。

限制：服务器返回 HTTP 200 但内容是错误占位图片时，浏览器仍会认为加载成功，插件无法可靠识别。

## 17. 全局搜索

本地索引覆盖：

- 所有层级子节点和折叠节点。
- 子导图和更深层后代子导图。
- 富文本、备注、标签、链接。
- 表格单元格和代码。
- 图片说明和资源路径。

索引监听文件创建、修改、重命名和删除，并按修改时间增量重建。

`Ctrl/Cmd+Alt+F`：当前父子导图族。

`Ctrl/Cmd+F` 保留给 Obsidian 默认搜索，`Ctrl/Cmd+Shift+F` 打开“全局搜索所有思维导图”。全库导图搜索也可通过工具栏的“全局搜索所有导图”按钮打开。

可在“快捷键配置”中点击“全局搜索”输入框并直接按下新的 1 至 3 键组合，保存后立即生效。

导图族搜索快捷键在正文、标题、节点输入框或其他可编辑区域聚焦时仍然有效，并兼容非英文键盘布局。

点击结果会打开文件、展开祖先、选中节点并居中。

结果行使用独立的可访问操作区域和替换按钮，避免嵌套按钮造成浏览器重排；可用鼠标点击、`Enter` 或空格打开结果。

## 只读与编辑切换性能

切换锁按钮不会重新计算导图布局、清空节点画布或重建文章内容。插件会在原有 DOM 上直接更新节点拖拽能力、工具栏和尺寸控制点；进入编辑模式后，文字仍保持普通阅读元素，只有点击的当前行才临时启用 `contenteditable` 并显示编辑外框，失焦后恢复普通排版。阅读状态的持久化延后到下一轮事件循环，因此大型导图和长文章也会先立即响应点击。实际修改节点内容、切换显示模式或更换文档时仍会按需完整渲染。

通读模式属于跨多个文件的连续阅读视图。切换为编辑时会自动返回当前导图的文章编辑模式，避免在连续书籍中产生跨文件写入歧义。

## 18. 主题和彩色分支

内置主题同时设置：

- 背景与图案。
- 根节点和普通节点颜色。
- 字体与字号。
- 连接线样式和颜色。
- 一级分支循环配色。

彩色分支按一级节点分组，同一一级分支的全部后代继承该颜色。

## 19. 连接线从粗到细

渐细模式按当前实际可见最大深度插值：

- 一级连接线使用起始宽度。
- 最深可见连接线达到最小宽度。
- 展开或折叠后重新计算。
- SVG 导出使用相同算法。

每条线同时写入 SVG 属性和内联样式，降低 Obsidian 社区主题覆盖线宽的风险。

## 20. 撤销与重做

可撤销操作统一经过 `mutate()`，包括内容、结构、样式、尺寸、任务状态、表格、代码和子导图引用。历史记录保存文档快照，并限制最大长度，避免长期编辑无限占用内存。

跨文件创建子导图、上传网络图片等外部副作用无法完全通过单文件撤销回滚，因此实现中会先后保存关键状态并提供安全检查。

## 21. Markdown 与 SVG 导出

Markdown 导出保留：

- 层级列表。
- 任务状态。
- 富文本常见样式。
- 标准 Markdown 超链接。
- 图片、表格和代码块。

HTML、Word、PDF 和 Markdown 文档导出始终以通读内容为来源。导出目录使用与文章/通读目录相同的最大层级设置；父导图中的子导图目录项会链接到实际子导图章节，Markdown 使用普通标题链接，Word 生成带书签和内部链接的 .docx，PDF 在桌面端直接保存到所选位置。

SVG 导出保留：

- 布局、主题、节点尺寸和对齐。
- 彩色分支。
- 渐细连接线。
- 富文本和任务图标。

## 22. 一键恢复初始设置

设置页的一键恢复只重置插件设置，不删除或修改已有 `.mindmap` 文件。恢复后刷新所有打开视图，并重新使用默认主题、默认显示模式、默认节点样式和默认搜索配置。

## 23. 多选节点剪贴板

同时选中多个节点后，复制或剪切会按导图中的原始顺序写入全部顶层分支；如果父节点和其后代同时被选中，只复制父分支一次。粘贴为子节点时会按该顺序还原全部分支、保留各自的后代内容，并为新节点生成新的 ID。

插件剪贴板使用当前多节点 JSON 载荷，同时支持 Markdown、缩进文本和 HTML 列表导入。剪切后的批量删除与复制使用同一份顶层选中节点集合，因此不会遗漏已复制的分支。

`Ctrl/Cmd+A` 会选中当前导图中的全部非主节点（包括折叠分支内的节点），主节点始终不会被加入多选，便于安全地批量复制、剪切或调整节点。

## 24. XMind 与 Markdown 导入

XMind 导入会递归保留所有主题层级，并识别画布 ID 或根主题 ID 形式的 `xmind:#链接ID`。被其他画布引用的子导图会挂回来源主题下；没有链接的额外画布也会作为独立分支导入，避免内容被丢弃或重复生成孤立分支。

Markdown 导入同时识别标题和有序、无序列表。标题下的列表会继续作为该标题的子分支，列表缩进会保留父子关系，不会因为标题与列表层级相同而被错误拉平。Markdown 表格也会被保留，解析后挂载到所属的标题或列表节点上。网页剪藏常见的 YAML 标题、普通图片和“图片外包原文链接”格式会分别保留为导图根标题和可移动图片内容块。

导入生成的每个文字节点会立即持久化为带稳定块 ID 的 `content`。因此导入后第一次在文章模式修改标题并按 Enter，会直接替换原标题，不会保留旧标题并额外新增一个正文文字块；只有旧版 `text/richText` 字段的已有文件也使用相同的原位更新兼容逻辑。

Markdown 行内的 `**加粗文字**` 会转换为节点富文本的加粗样式，节点文字不保留 `**` 标记；导图、大纲和文章视图共享该样式。

没有 Markdown 标题或列表、仅使用整行加粗文本组织的提纲同样可以导入：首个加粗行作为根节点，`主题一`、`主题二` 等主题标记成为同级分支，其他加粗行与普通文本归属当前主题，避免首个主题吞并后续主题。

如果文件开头含有 `目录` 标题和 Markdown 表格，目录会被识别为导航信息并跳过，文件名保留为根节点，之后的一级主题保持为同级分支。引用文字和普通段落会归属当前标题或列表节点，避免导入时丢失正文。

## 25. 文件导入进度

通过“导入 XMind / Markdown”选择文件后，导入窗口会显示读取、解析和生成思维导图三个阶段的进度。XMind 会明确提示正在解析画布和主题，Markdown 会提示正在解析标题和列表；完成前保留窗口与 100% 状态，导入失败时在进度区域显示原因。

## 26. 粘贴与导入后的默认折叠

粘贴节点分支后，粘贴出的节点及其后代会默认收起，避免大分支立即铺满画布。导入 XMind、Markdown 或 JSON 文档时，根节点保持展开，所有包含子节点的非根分支默认收起；用户仍可从一级结构开始按需展开。

## 27. 双指手势与缩放输入

设置中的“双指手势”可分别控制触控板和触摸屏上的双指操作：选择“放大缩小”时，触控板双指滚动与触摸屏双指捏合会以手势中心为锚点缩放画布；选择“移动画布”时，双指操作会平移画布。

工具栏中的缩放百分比可直接输入，例如输入 `125` 或 `125%` 后确认即可缩放到 125%；无效或非正数输入会恢复为当前缩放比例。


## AI 助手

AI 助手把当前物理导图或指定节点子树转换为 Markdown，再发送到用户选择的 OpenAI Chat Completions 兼容接口。工具栏和快捷键默认使用当前页面；节点右键将范围限定到该节点及后代，空白处右键恢复整页。窗口提供问答、AI 整理并重新生成、图片识图和本地文字替换四种模式。图片识图会按节点树顺序处理当前范围全部图片；可切换 AI 视觉模型或本机 Tesseract OCR。AI 编辑只生成 Markdown 提案，经过本地解析、预览和明确确认后才替换节点，并写入撤销历史；本地替换完全不联网。发送窗口显示 UTF-8 大小和节点数量，超过设置上限时阻止 AI 请求。请求期间显示上传上下文、模型处理和解析结果等阶段、动态进度条及已等待秒数；OpenAI 兼容客户端为非流式请求，无法取得真实完成百分比，因此不会显示虚假百分比。等待超过 30 秒时会提示长内容或繁忙模型可能需要更久。接口配置、结构化编辑边界、安全和隐私见 `AI_ASSISTANT.zh-CN.md`。


## 截图与识别

图片在导图、大纲和文章视图中都提供右键识图入口。插件读取图片后打开原图与可编辑文字的并排预览；识图确认可设置为直接、5/10/15 秒后自动或手动。替换会把图片块在原位置转换为文字块，并写入撤销历史；未被其他导图引用的本地图片会自动删除。预览后图片被修改时，旧预览不会覆盖新内容。

“截图”和“截图并识别”是独立命令、独立快捷键和独立右键入口，不再依赖自动识图开关。桌面端优先打开可调整选区的截图覆盖层，左上显示全局坐标和尺寸。默认选区覆盖当前屏幕完整范围；普通截图显示几何图形、画笔、箭头、文字、序号、马赛克、橡皮擦、识别并复制、下载、取消和复制工具栏，不会自动关闭，双击选区后复制并插入；截图并识别视觉上隐藏底部工具栏，但保留完整控件 DOM 并禁用指针事件；倒计时沿用原有“秒后自动识别”胶囊提示，仅将数字显示为整数 `3、2、1`，悬停选区边框、拖动条或缩放手柄时暂停，离开或重新框选后从 3 秒重启，Esc 在 iframe 与宿主窗口都可退出。截图开始前会冻结节点或内容块目标；截图并识别在插入后运行当前 AI/OCR 方式。详细平台和 Tesseract 配置见 `IMAGE_RECOGNITION_SCREENSHOT.zh-CN.md`。

## 图片失败地址与安全后台上传

- 所有图片候选来源加载失败时，四种显示模式直接显示原始地址、镜像地址和本地地址，并提供复制按钮。
- 外部图片粘贴在文件保存前锁定目标节点；异步期间选择变化不会让图片跳到其他节点。
- 第二次打开包含多张待上传图片的文件时，同一文件的任务合并处理并只显示汇总通知。上传结果按节点和图片块 ID 合并到最新文档，避免多任务用旧快照互相覆盖。
- 文章前后页导航按钮不注册 `title` 或按钮级 `aria-label` 悬浮提示属性；按钮自身可见文字继续承担操作说明。

## 全局页面过渡

导图模式切换、文章目录与章节、父子导图导航、创建/提取子导图及合并回主导图共用一套状态卡片。大文件操作先显示中文状态，再进行保存、复制和解析；目标内容完成后淡入。过渡层会阻止重复点击，异常时自动退出并提示，减少动态效果设置下改为静态状态。
