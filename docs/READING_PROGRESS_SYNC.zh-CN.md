# 四模式阅读进度同步说明

## 目标行为

导图、大纲、文章和通读使用同一个语义阅读位置，而不是各自保存互不相关的滚动条：

1. 在导图中选中节点后切换到其他模式，目标模式定位该节点。
2. 在大纲、文章或通读中滚动后切换模式，以视口 35% 高度处的节点作为阅读锚点。
3. 从文章切到导图或大纲进行临时修改后返回文章，会直接以当前模式的节点作为正文显式目标，不重新落到目录，也不沿窗口顶部连续补载前文。
4. 通读锚点属于子导图时，切换到导图、大纲或文章会打开对应物理 `.mindmap` 文件。
5. 关闭视图、退出 Obsidian、重新打开顶层导图或子导图后，继续恢复同一文章族的最近位置。
6. 目标节点不存在时回退到保存时的直接父节点，然后依次回退到祖先和根节点。
7. 目标子导图不存在时回退到父导图中的挂载节点，再沿父导图祖先链回退。

## 启动模式规则

- 导图、文章和通读可以作为下次启动模式。
- 大纲只在当前会话内作为全局模式同步。
- 退出时处于大纲，不会把 `outline` 写入下次启动设置。
- 加载到 `outline` 时会解析为可持久化模式：优先导图，导图被隐藏时使用可见的文章或通读模式。

## 持久化结构

阅读位置保存在插件设置的 `readingLocations` 中，并按文章族顶层文件分组：

```json
{
  "readingLocations": {
    "书籍.mindmap": {
      "filePath": "MindMap Assets/书籍/第二章.mindmap",
      "nodeIds": ["section-2-2", "chapter-root"],
      "fallbacks": [
        {
          "filePath": "书籍.mindmap",
          "nodeIds": ["chapter-2-link", "book-root"]
        }
      ],
      "nodeRatio": 0.25,
      "viewportRatio": 0.35
    }
  }
}
```

字段含义：

| 字段 | 含义 |
|---|---|
| `filePath` | 当前锚点所在物理导图 |
| `nodeIds` | 精确节点到当前文件根节点的回退顺序 |
| `fallbacks` | 子导图到父导图挂载节点的跨文件回退顺序 |
| `nodeRatio` | 锚点位于节点内部的相对位置 |
| `viewportRatio` | 锚点位于视口中的相对位置 |

通读进度条根据当前滚动位置实时计算，不再维护第二套持久化百分比。

```text

```

## 回退算法

给定保存位置：

```text
子导图 / 第二章 / 第二节 / 测试
```

恢复时依次尝试：

```text
测试
→ 第二节
→ 第二章子导图根节点
→ 父导图中的“第二章”挂载节点
→ 父导图根节点
```

只要找到第一个仍存在的节点即停止回退。节点移动但 ID 保持不变时仍精确恢复目标，不会错误回到旧父级。

## 写入与并发规则

- 滚动捕获使用 160 ms 防抖。
- 设置写盘使用 350 ms 防抖。
- 视图销毁和主动模式切换会立即刷新内存状态并发起保存。
- 全局模式广播到其他已打开视图时，其他视图会取消尚未落盘的延迟写入，只切换自己的界面，不覆盖发起视图刚保存的位置。
- 文章正文返回事务会在重绘前把导图或大纲当前节点写入 `pendingArticleFocusLocation`；程序化语义恢复期间暂停文章窗口边缘自动扩展，只有用户重新滚动后才允许加载前文或后文。
- 异步文章上下文使文章族顶层路径发生变化时，先按旧文章族键刷新待写位置，再加载新文章族位置，防止串写。
- 顶层导图仅作为目录页时，目录项保留节点语义锚点；子导图章节开头同时提供父导图挂载节点别名，因此从挂载节点进入通读仍能落在对应章节。
- `.mindmap` 文件重命名时，同时迁移主路径、父级回退路径和文章族键。

## 验证清单

自动测试覆盖：

- 大纲不作为启动模式。
- 导图隐藏时的启动模式回退。
- 节点到根节点的祖先顺序。
- 跨子导图父级回退链。
- 节点删除后的最近祖先恢复。
- 子导图缺失后的父挂载节点恢复。
- 路径重命名迁移。
- 非法磁盘记录与比例边界规范化。
- 目录页、父挂载节点锚点和多视图延迟写入隔离。

Obsidian 手动冒烟应至少验证：

1. 在文章中滚动到中段，切到导图修改当前节点，再切回文章，确认直接定位当前文字且不会连续加载前文到页首。
2. 在导图点击“第二章 → 第二节 → 测试”，依次切换大纲、文章、通读、导图。
3. 在通读滚动到子导图章节后切换文章，确认打开对应子导图并定位节点。
4. 关闭视图和重启 Obsidian 后重新打开顶层文件。
5. 删除目标节点，确认回到直接父级；继续删除父级，确认逐级回退。
6. 删除目标子导图，确认回到父导图挂载节点。
7. 重命名顶层或子导图，确认位置仍可恢复。
