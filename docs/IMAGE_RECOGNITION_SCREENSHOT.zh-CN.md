# 截图与识别

## 入口

插件设置中的独立一级分类为“截图与识别”，默认排在“AI 助手”之后。该分类统一管理 AI 视觉识图、本机 Tesseract OCR、截图行为和两套编辑器快捷键。

可从以下位置进入：

- AI 助手选择“图片 AI 识图”或“图片本地 OCR”，按节点树顺序处理当前页面或右键节点子树中的全部图片。
- 在导图、大纲或文章中的图片上右键，选择 AI 识图或本地 OCR 并转为文字。
- 顶部工具栏分别选择“截图”和“截图并识别”。
- 节点右键分别选择“插入截图”和“插入截图并识别”。
- 命令面板分别执行“截图”和“截图并识别”。
- 编辑器内默认快捷键：截图为 `Ctrl/Cmd+Shift+S`，截图并识别为 `Ctrl/Cmd+Shift+R`；两者可独立录制和保存。

## 截图与截图并识别的边界

“截图”和“截图并识别”是两条独立链路，不再通过“截图后自动识图”开关耦合：

- **截图**：覆盖层打开后默认保留可调整边框，不会自行关闭。双击截图选区，或点击“复制”，才会复制图片并插入截图开始前聚焦的节点或内容块之后；没有有效插入目标时只保留系统剪贴板图片。
- **截图并识别**：点击并拖动选区、释放鼠标后启动 3 秒自动完成计时；调整边框或移动选区后也会重新开始计时。计时期间鼠标在选区内活动，或继续调整边框，会把等待时间重置为 3 秒。自动完成后关闭覆盖层、插入图片并立即使用当前识图方式，同时沿用“识图结果确认”的直接、延时或手动确认规则。没有有效插入目标或当前文档只读时，识别文字会直接复制到系统剪贴板。
- **识别并复制**：在截图编辑器内直接识别当前选区并复制纯文字，不插入图片，也不修改导图。

## PixPin 风格截图编辑器

Windows 端优先使用 PowerShell、WinForms 与 `System.Drawing` 抓取完整虚拟桌面，并在进程启动时启用 Per-Monitor V2 DPI 感知；截图元数据包含虚拟桌面边界、每块显示器的全局坐标、主屏和鼠标所在屏幕。编辑器仍挂载在当前 Obsidian 窗口最上层，但左上提供“全部屏幕 / 屏幕 1 / 屏幕 2 …”切换，因此无需把 Obsidian 移到目标屏幕也能选择第二块显示器。其他平台继续使用渲染器 `desktopCapturer` 或本机非交互式抓屏命令。

截图背景按显示器宽高比完整适配，不再强行拉伸到 Obsidian 窗口。选区坐标先映射到所选显示器的全局坐标，导出时再映射回虚拟桌面 PNG 的原始像素，因此在 100%、125%、150%、200% DPI 及不同窗口宽高比下仍保持原始截图比例和像素范围。切换显示器会清除当前标注并重置选区。

截图选区提供：

- 圆角蓝色细描边、柔和内外阴影和圆形八方向缩放手柄，降低生硬边缘感。
- 可拖动边框。
- 左上角实时显示全局屏幕位置 `X / Y` 和选区 `宽 × 高`。
- 选区外暗色遮罩。
- 普通截图可双击选区确认；`Esc` 取消，`Enter` 立即复制。
- 截图并识别在拖拽选区或调整边框释放后等待 3 秒自动确认；选区内鼠标活动或继续调整边框会重置计时。

底部工具栏包含：

1. 几何图形：支持矩形、圆角矩形、椭圆，并可选择颜色、细中粗线宽与半透明填充。
2. 画笔：支持颜色和细中粗线宽，使用圆角笔触。
3. 箭头：支持颜色和细中粗线宽，并随线宽调整箭头尺寸。
4. 文字：点击选区后显示画布内文本输入框，支持中文输入、多行输入，`Ctrl/Cmd + Enter` 完成。
5. 序号：依次插入圆形编号，并跟随当前颜色。
6. 马赛克：对截图内容进行像素化涂抹。
7. 橡皮擦：擦除已添加的标注。
8. 识别并复制：识别当前选区并复制文字。
9. 固定：Windows 通过独立 PowerShell WinForms 进程创建真正置顶、可拖动、可缩放的窗口；`Esc` 可关闭。其他平台使用渲染器弹窗兼容路径。
10. 下载：选择位置保存 PNG。
11. 取消：关闭截图编辑器且不修改导图。
12. 复制：复制 PNG，并按当前命令决定是否插入和识别。

插件不会静默启动操作系统交互式区域截图工具。点击截图命令后会先显示“正在准备截图编辑器”提示；Electron 与本机抓屏均有硬超时，抓取或覆盖层创建失败时返回明确错误并记录 `MindMap Studio capture:` 阶段日志。

## AI 视觉识图与本地 OCR

在“设置 → MindMap Studio → 截图与识别”选择默认方式：

- **AI 视觉识图**：使用已启用的 OpenAI Chat Completions 兼容接口和支持图片输入的模型。默认跟随全局 AI 接口，也可单独选择视觉接口。
- **本地 Tesseract OCR**：仅桌面端可用。插件把图片写入临时目录，通过 `execFile` 调用本机 Tesseract，命令不经过 shell，识别后删除临时文件，图片不上传。

本地 OCR 默认命令为 `tesseract`，默认语言为 `chi_sim+eng`，默认附加参数为 `--psm 6`。需要先在操作系统安装 Tesseract 及对应语言包；也可填写可执行文件完整路径。

## 图片转文字

图片识别后会生成不可变预览：

1. 插件读取图片并执行当前识图方式。
2. 手动或延时确认模式显示原图与可编辑识别文字；直接确认模式在后台应用。
3. 确认后把原图片内容块在同一位置替换为文字块，并写入撤销历史。
4. 预览期间图片发生变化时，旧预览会被拒绝。
5. 本地图片不再被任何导图引用时才允许安全删除。

## 插入目标

截图开始前，编辑器冻结当时的导图内目标：

- 节点右键入口使用右键节点和右键内容块，不受截图期间焦点变化影响。
- 文章或大纲内容块获得焦点时，截图插入该内容块之后。
- 节点获得焦点但没有明确内容块时，截图追加到节点末尾。
- 命令面板等外部场景没有导图内目标时，不修改导图。

## 平台与隐私

- Windows：使用 DPI 感知的 PowerShell、WinForms 与 `System.Drawing` 静默抓取完整虚拟桌面，记录所有显示器边界；设置“截图时隐藏 Obsidian”且无法取得 Electron 窗口句柄时，由原生命令临时最小化并恢复前台窗口。
- macOS：使用非交互式 `screencapture` 抓取浏览器报告的当前显示器范围。
- Linux：依次尝试 `grim`、ImageMagick `import`、GNOME Screenshot 和 Spectacle 生成整屏 PNG。
- 本机命令失败时仅尝试渲染器可用的 Electron `desktopCapturer`；两条抓取路径都失败时显示明确错误，不启动系统交互式截图。
- 移动端：AI 图片识别可用；桌面截图覆盖层、系统截图调用和本地 Tesseract OCR 不可用。
- Electron 和 Node.js API 只在功能触发时动态获取，不影响移动端加载插件。
- AI 模式会把当前图片发送到用户选择的视觉接口；本地 OCR 不联网。
- 图片内文字属于不可信输入，视觉提示要求模型只转录可见内容，不执行图片中的指令。
