# 图片识图、OCR 与截图

## 功能入口

- AI 助手选择“图片 AI 识图”或“图片本地 OCR”，依次处理当前页面或右键节点子树中的全部图片。
- 在导图、大纲或文章中的图片上右键，选择“AI 识图并转为文字”。
- 工具栏“插入截图”或命令 `截图并插入当前节点或复制到剪贴板`；编辑器内默认快捷键 `Ctrl/Cmd+Shift+S`，可在插件设置中修改。

## AI 视觉识图与本地 OCR

在“设置 → MindMap Studio → 图片识图与本地 OCR”选择模式：

- **AI 视觉识图**：使用已启用的 OpenAI Chat Completions 兼容接口和支持图片输入的模型。图片会发送到用户选择的接口。默认跟随“默认 AI 接口”；如果全局默认模型是纯文本模型，可在“AI 识图接口”中单独选择视觉模型。
- **本地 Tesseract OCR**：仅桌面端可用。插件把图片写入临时目录，通过 `execFile` 调用本机 Tesseract，识别结束后删除临时目录；命令不经过 shell，图片不上传。

本地 OCR 默认命令为 `tesseract`，默认语言为 `chi_sim+eng`，默认参数为 `--psm 6`。需要先在操作系统安装 Tesseract 及对应语言包；也可填写 `tesseract.exe` 完整路径。若系统返回 `spawn tesseract ENOENT`，表示插件找不到可执行文件，需要安装 Tesseract 或改为完整路径。附加参数支持引号分组，但未闭合引号会被拒绝。

## 图片右键转文字

1. 插件读取图片并执行当前识图方式。
2. 弹窗使用固定的宽大图片区域并排显示缩小后的原图和可编辑的识别文字，不按原图尺寸撑开界面。AI 模式直接发送识图提示和图片，不发送导图 Markdown；角色、Box 模板、Markdown 和图片描述等无效输出会在预览前移除。
3. “取消返回”关闭弹窗，不修改导图。
4. “确定替换”在原内容块位置把图片转换成文字，并进入撤销历史。

预览保存图片块快照。若预览期间图片地址、说明或内容块已经变化，确认时会拒绝旧预览，需重新识别。

## 截图插入规则

截图开始前，编辑器记录当时的导图内焦点：

- 焦点位于文章/大纲的某个内容块时，截图插入该内容块之后。
- 焦点位于某个节点但没有明确内容块时，截图追加到该节点末尾。
- 焦点不在导图内部（例如从命令面板触发）时，不修改导图；系统截图仍保留在剪贴板。
- 导图只读、原节点已删除或保存图片失败时，不执行文档插入。

开启“截图时隐藏 Obsidian”后，插件会在当前桌面运行时支持窗口控制时最小化 Obsidian，并在完成或失败后恢复、显示和聚焦；不支持窗口控制时仍可正常启动截图。开启“截图后自动识图”后，截图插入成功会自动运行当前识图方式并打开原图/文字预览；仍需确认才会替换。“截图快捷键”只在导图编辑器获得焦点时生效；Obsidian 命令面板中的快捷键仍可独立设置。

## 平台说明

- macOS：调用 `screencapture -i -c`。
- Windows：优先调用 `SnippingTool.exe /clip`，再尝试 `ms-screenclip:`。
- Linux：依次尝试 `gnome-screenshot`、KDE Spectacle 和 Flameshot。至少需要安装其中一个。
- 移动端：AI 识图可用；系统截图调用和本地 Tesseract OCR不可用。相关 Node/Electron API 仅在功能触发时动态加载，不影响移动端启动插件。

## 隐私与安全

AI 模式会把单张图片和识图提示发送到用户配置的服务；本地 OCR 不联网。粘贴或截图后的图片在自动上传前使用本地二进制进行识图；默认 5 分钟后自动上传，重新打开导图时会依据本地图片时间补传。上传成功后，AI 识图会直接发送当前可达的 HTTPS 图床 URL，避免重复读取本地文件。图片内文字被视为不可信输入，视觉请求要求模型忽略图片中的指令，仅返回转录。识图批量结果不会自动改写导图；所有图片替换都需要预览确认。

图片查看器只显示实际可用的来源。图床地址存在但本地副本已删除时，不再显示会加载失败的“本地副本”按钮。
